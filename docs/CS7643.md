## What the class is

Math + implementation of deep nets (not a Keras cookbook). Modules:

1. Neural nets — linear classifiers, MLPs, backprop, autodiff, regularization, optimization
2. CNNs — conv/pool, architectures, visualization, PyTorch, a bit of fairness / advanced CV
3. Sequences — RNNs, embeddings, attention, transformers, NMT (this is the coding beast; was A4, now A3 since Spring 2025)
4. Advanced — RL survey, unsupervised, VAEs / GANs / diffusion (A4 since Spring 2025)

Grade (Fall 2025 syllabus): Assignments 60% (4 × 15%), Quizzes 18.75%, Project 20%, PS0+Quiz0 1.25%. Homework/project: 48h grace. Quizzes: **no grace**. Due 8:00 AM **Eastern** = 5:00 AM Pacific. Submit the night before.

Prereq: real ML class (CS 7641 or equivalent). Strong Python. GPU optional (Colab is enough).
